# Pizzeria De La Casa App 2

¡Bienvenido a **Pizzeria De La Casa App 2**!  
Este es un proyecto desarrollado en **Android Studio** utilizando **Java** como lenguaje principal. La aplicación está diseñada para gestionar los pedidos, menús y operaciones de una pizzería, brindando una experiencia intuitiva tanto para los clientes como para los administradores.

---

## 🚀 Descripción General

**Pizzeria De La Casa App 2** es una aplicación móvil que permite a los usuarios:
- Visualizar el menú de pizzas y otros productos.
- Realizar pedidos personalizados.
- Consultar el estado de sus pedidos.
- Administrar el historial de compras.

La aplicación también incluye funcionalidades para la gestión interna de la pizzería, como el manejo de inventario y la administración de pedidos por parte del personal.

---

## 📱 Características Principales

### Para Clientes
- **Explorar Menú:** Catálogo de pizzas, bebidas y complementos con imágenes y descripciones.
- **Personalización de Pedidos:** Selección de ingredientes, tamaños y tipos de masa.
- **Carrito de Compras:** Añadir, modificar o eliminar productos antes de confirmar el pedido.
- **Seguimiento en Tiempo Real:** Visualización del estado del pedido (preparación, en camino, entregado).
- **Pagos:** Opciones de pago en efectivo o digital (según integración).
- **Historial de Pedidos:** Consulta de pedidos anteriores y repetición rápida.

### Para Administradores/Personal
- **Gestión de Pedidos:** Visualización y actualización del estado de los pedidos.
- **Inventario:** Registro y control de ingredientes y productos.
- **Gestión de Usuarios:** Administración de cuentas de clientes y empleados.
- **Reportes:** Consultas de ventas y estadísticas básicas.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java
- **IDE:** Android Studio
- **Arquitectura:** MVC/MVVM (dependiendo de la implementación)
- **Base de Datos Local:** SQLite o Room (según el caso)
- **Interfaz de Usuario:** XML
- **Conexión Remota (Opcional):** REST API para pedidos en línea (si aplica)

---

## 📂 Estructura del Proyecto

- `/app/src/main/java/`  
  - **activities/**: Actividades principales (pantallas) de la app.
  - **adapters/**: Adaptadores para listas y vistas dinámicas.
  - **models/**: Clases de datos (Pizza, Pedido, Usuario, etc).
  - **database/**: Gestión de base de datos local.
  - **utils/**: Utilidades y helpers.
- `/app/src/main/res/layout/`  
  - Archivos XML para las interfaces de usuario.
- `/app/src/main/res/drawable/`  
  - Imágenes y recursos gráficos.
